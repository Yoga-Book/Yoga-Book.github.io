== Engineering principles

[cols="1,1,1",options="header",stripes=none,role=principles]
|===
|Focused ownership
|Verifiable results
|Safe by default

|Kernel, userspace, packaging, and validation concerns stay in explicitly scoped repositories.
|Build results, VM checks, and physical-device acceptance are reported as different kinds of evidence.
|Installation and diagnostic workflows favor explicit targets, recovery paths, and reproducible results.
|===

== Primary target

The Lenovo Yoga Book **YB1-X91L** is the primary integration and acceptance target.
Individual projects document any additional supported models and the evidence available for them.
