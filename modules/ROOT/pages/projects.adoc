== Documentation ownership

This site is the curated organization-level handbook: installation paths, support boundaries, cross-project architecture, validation, and troubleshooting.

Exact build procedures, implementation details, release manifests, and component-specific acceptance records remain in the repository that owns them. The handbook links those sources and records its review date instead of silently presenting a copied procedure as permanently current.
