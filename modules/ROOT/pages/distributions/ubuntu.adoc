= Ubuntu
:description: Install the Yoga Book package set on a supported Ubuntu release.

This guide configures Imanuel Ulbricht's Ubuntu package repository and installs the Yoga Book package set.

https://ubuntu.yogabook.ulbricht.casa/[ubuntu.yogabook.ulbricht.casa,window=_blank]

== Ubuntu 26.04 LTS (Resolute Raccoon)

[source,console]
----
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl --fail --show-error --location \
  https://packages.ulbricht.casa/api/packages/linux-yogabook/debian/repository.key \
  --output /etc/apt/keyrings/forgejo-linux-yogabook.asc
echo 'deb [signed-by=/etc/apt/keyrings/forgejo-linux-yogabook.asc] https://packages.ulbricht.casa/api/packages/linux-yogabook/debian resolute main' \
  | sudo tee /etc/apt/sources.list.d/forgejo-linux-yogabook.list
sudo apt update
----

== Install the package set

[source,console]
----
sudo apt install linux-image-yogabook linux-headers-yogabook halo-keyboard alsa-ucm-conf-yogabook yogabook-sensors yogabook-gnss yogabook-camera yogabook-validator
----

This installs the patched kernel and headers, Halo keyboard driver, ALSA UCM configuration, sensor policy, GNSS and camera support, and Yoga Book Validator.

Keep the generic Ubuntu kernel installed as a fallback until the Yoga Book kernel and device-specific packages have passed the required physical checks.

For a complete Yoga Book system image rather than packages on an existing installation, use the xref:get-started.adoc[Ubuntu Autoinstall workflow].
