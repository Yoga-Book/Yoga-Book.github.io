== Add the Edge repository

The packages are built against the current Alpine Edge branch. Run these commands as `root`:

[source,console]
----
echo 'https://packages.ulbricht.casa/api/packages/linux-yogabook/alpine/edge/yogabook' \
  | tee -a /etc/apk/repositories
cd /etc/apk/keys/
curl --fail --show-error --location --remote-header-name --remote-name \
  https://packages.ulbricht.casa/api/packages/linux-yogabook/alpine/key
apk update
----

Review the downloaded key and the repository contents before installing packages. Alpine Edge is a rolling development branch; its risk profile differs from a stable release.

== Install the package set

[source,console]
----
apk add linux-yogabook linux-yogabook-dev yogabook-keyboard alsa-ucm-conf-yogabook yogabook-sensors yogabook-gnss yogabook-camera yogabook-validator yogabook-keyboard-openrc yogabook-gnss-openrc yogabook-camera-openrc
----

This installs the patched kernel and development files, Halo keyboard support, ALSA UCM configuration, sensor policy, GNSS and camera support, Yoga Book Validator, and the matching OpenRC services.

Keep a known-good boot path until the new kernel and OpenRC services have passed the required physical checks.
