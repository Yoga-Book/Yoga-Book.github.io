= Arch Linux
:description: Install the Yoga Book package set on Arch Linux.

This guide configures Imanuel Ulbricht's Arch package repository, installs the Yoga Book package set, and shows a `systemd-boot` entry for the Yoga Book kernel.

== Add the signing key

Download the repository key, import it into pacman's keyring, and locally sign it:

[source,console]
----
wget -O sign.gpg https://packages.ulbricht.casa/api/packages/linux-yogabook/arch/repository.key
sudo pacman-key --add sign.gpg
sudo pacman-key --lsign-key 'linux-yogabook@noreply.packages.ulbricht.casa'
----

Verify the displayed fingerprint against a trusted channel before locally signing the key.

== Add the repository

Append the repository definition to `/etc/pacman.conf`:

[source,console]
----
sudo tee -a /etc/pacman.conf <<'EOF'
[linux-yogabook.packages.ulbricht.casa]
Server = https://packages.ulbricht.casa/api/packages/linux-yogabook/arch/yogabook/$arch
EOF
----

== Install the package set

[source,console]
----
sudo pacman -Syu yogabook-keyboard alsa-ucm-conf-yogabook linux-yogabook linux-yogabook-headers intel-ucode yogabook-sensors yogabook-gnss yogabook-camera yogabook-validator
----

== Configure systemd-boot

The packaged kernel is named `vmlinuz-linux-yogabook`; its initramfs is `initramfs-linux-yogabook.img`. The Yoga Book uses an Intel Atom x5, so load `intel-ucode` before the initramfs.

Create `/boot/loader/entries/yogabook.conf`:

[source,text]
----
title Arch Linux for Yoga Book
linux /vmlinuz-linux-yogabook
initrd /intel-ucode.img
initrd /initramfs-linux-yogabook.img
options # Copy the working kernel options for this installation here
----

Replace the `options` placeholder with the installation's existing root, encryption, graphics, and other required kernel parameters. Keep a known-good boot entry while testing.

To select the new entry by default, set this line in `/boot/loader/loader.conf`:

[source,text]
----
#timeout 3
#console-mode keep
default yogabook.conf
editor no
# Add more custom options here
----

The source guide documents only `systemd-boot`. Adapt the kernel, initramfs, and microcode paths according to the documentation for any other bootloader.
