= Get started
:description: Choose the right entry point for installing, testing, or developing Yoga Book Linux.

The Yoga Book Linux organization coordinates the device-specific pieces needed to run Linux on the original Intel-based Lenovo Yoga Book. Start with the path that matches your goal.

== Install Linux

The xref:install-ubuntu.adoc[Ubuntu 26.04 installation guide] is the system-integration entry point for the YB1-X91L. It explains the destructive whole-disk boundary, image build, guarded USB writing, physical installation, first boot, and recovery evidence.

Before writing an image or changing an existing installation:

* confirm the exact Yoga Book model and firmware version;
* back up important data;
* keep a known-good boot or recovery option; and
* read the release notes and repository-specific requirements in full.

If Linux is already installed, community repositories provide Yoga Book packages for xref:distributions/index.adoc[Arch Linux, Debian, Ubuntu, and Alpine Linux].

== Check an existing system

Use xref:validation.adoc[Yoga Book Validator] to collect system facts and run automated checks. Treat its report as diagnostic evidence, not as a substitute for physical checks such as audio playback, pen input, rotation, cameras, or suspend and resume.

If a check fails, preserve the complete output and follow the xref:troubleshooting.adoc[symptom-oriented troubleshooting guide] before changing the system.

== Develop or test a component

Open the repository that owns the affected layer. Its README, contribution guidance, branches, and issue tracker are authoritative for that component.
